\game\ is played on a computer; a game server manages everything below.

\begin{description}[leftmargin=0pt,labelsep=0.5em]
  \item[The \VC{grid}] 108 \Vp{node} in \Rule{rows} rows (\node{0}--\node{8}) and \Rule{cols} columns (\node{A}--\node{L}).
    A \V{node} is named column first, then row: \node{A0} is the top-left corner, \node{L8} the bottom-right.
  \item[\VCp{exploit}] 108 of them, one for each \V{node}. An \V{exploit} can only be run against the \V{node} it is written for.
    Each \V{player} holds \Rule{kitsize} \Vp{exploit}, called their \term{\V{kit}}. Your \V{kit} is secret.
  \item[Syndicates] Seven crime syndicates, each with its own \V{coin}. Only one \V{hive} per syndicate can be on the \V{grid} at a time.
  \item[\VC{money} (\Game{currency})] The region's currency. Each \V{player} starts with \Y{\Rule{startcash}}.
  \item[\VCp{coin}] \Rule{coinsupply} of each syndicate's \V{coin}. \VC{coin}'s value in \V{money} increases as \Vp{hive} spread. \VCp{coin} not owned by the \Vp{player} is held by the \V{bank}.
  \item[The \V{bank}] The bank. It sells \V{coin}, buys it back, and pays out bonuses. There are no loans.

\end{description}
