**SYN-ACK WIRE** is a strategic cyberpunk-themed network game for the
[FujiNet](https://fujinet.online/) for two to six players (or solo vs bots).
This release is for the Atari 8-bit computers.

**Atari:** boot `synack.atr` from FujiNet. It joins the public server's CHIBA-GRID-7 table. The game has built-in help. The PDF of the complete manual is included below.
