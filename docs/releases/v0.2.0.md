**SYN-ACK WIRE** v0.2.0 introduces the game to Apple II users. Apple II and Atari players can compete at the same table.

**Apple II (new):** for the IIe, IIc and IIgs with FujiNet. Pick a SYN-ACK WIRE table in the FujiNet game
lobby, or boot `syn-ack-wire-apple2.po` from FujiNet: it joins the public server's CHIBA-GRID-7 table. The
game has built-in help, with a QR code to the manual. The PDF of the complete manual is included below.

**Atari:** the last move now blinks for five seconds, then shows as usual. Boot `syn-ack-wire-atari.atr` from
FujiNet, or pick any table from the FujiNet game lobby. The game has built-in help. The PDF of the complete
manual is included below.
