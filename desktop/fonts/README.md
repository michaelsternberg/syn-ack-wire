# Fonts

The desktop client's font themes. Each is shipped with its licence; all come from
[google/fonts](https://github.com/google/fonts) (`ofl/`). Lines, boxes, blocks and the currency sign are drawn
by the program, not taken from these.

| File | Font | Theme | Licence |
|---|---|---|---|
| `JetBrainsMono.ttf` | JetBrains Mono (variable) | Normal; also the menus | SIL OFL 1.1 (`JetBrainsMono-OFL.txt`) |
| `ShareTechMono-Regular.ttf` | Share Tech Mono | Share Tech Mono | SIL OFL 1.1 (`ShareTechMono-OFL.txt`) |
| `Orbitron.ttf` | Orbitron (variable) | Orbitron | SIL OFL 1.1 (`Orbitron-OFL.txt`) |
| `Oxanium.ttf` | Oxanium (variable) | Oxanium | SIL OFL 1.1 (`Oxanium-OFL.txt`) |
| `VT323-Regular.ttf` | VT323 | VT323 Terminal | SIL OFL 1.1 (`VT323-OFL.txt`) |
| `ChakraPetch-Regular.ttf` | Chakra Petch | Chakra Petch | SIL OFL 1.1 (`ChakraPetch-OFL.txt`) |
