; The NES client's 8x8 font, in the CHR-RAM's background tiles: codes $20-$7E, then
; the title logo's box glyphs at $01-$0B. tools/font_nes.py turns it into src/nes/font.inc,
; one bit a pixel; the client sets the tiles from it at start-up (src/nes/ppu.s), each also
; inverse at code | $80. Edit here, not there.
;
; Each glyph: its code and a name, then 8 rows of 8 pixels, # lit and . dark.
; The glyphs are the NES CONFIG's (fujinet-config, nes/font.txt): Family BASIC's manner,
; 7x7 strokes in the cell's top left, the 8th row and column the gap between cells, a
; slashed zero, lower case dropping into the 8th row. Lower case is only in the help
; pages; the server sends nothing above $5F.
; $5C is the yen sign, as on the Atari: the server sends "\" for money.
